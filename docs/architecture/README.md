# 포트폴리오 아키텍처

정적 Astro 포트폴리오. C1은 시스템 맥락, C2는 실행·배포 단위, C3는 그 내부 책임을 나타낸다. C4는 코드 링크로 연결한다. 웹·인쇄는 같은 HTML을 사용한다.

| 단계 | 지도 | 확인할 내용 |
|---|---|---|
| C1 · Context | [시스템 맥락](01-context.md) | 독자·편집자·외부 시스템 |
| C2 · Container | [컨테이너](02-containers.md) | 브라우저·정적 호스팅·빌드 경계 |
| C3 · Component | [컴포넌트](03-components.md) | 콘텐츠·렌더링·동작·스타일 책임 |
| C4 · Code | [코드 경로](04-code.md) | 실제 구현으로 이동 |

[SOLID·중복 분석과 변경 판단](refactoring.md). `pnpm verify`는 C4를 포함한 이 폴더의 로컬 링크를 검사한다. 실행 단위·책임·의존성이 달라지면 해당 지도와 코드 경로를 함께 갱신한다.
